1. Vertical vs. Horizontal Software: 

Vertical Packages:

Assist users within a specific, specialized industry segment

Examples: Software that manages construction projects, tracks inventory in hospitals, or handles fast-food outlet orders 

Horizontal Packages:

Perform a general function across a wide range of different businesses

Examples: Accounting software, word processors, spreadsheet packages, or office automation tools.


2. Operating System Modes:

COMPARING BATCH AND REAL TIME PROCESSING:

Batch Processing: Pocessing program in batches without user interaction

Real-Time Processing: Systems that respond to an event within a fixed time interval (e.g., in manufacturing plants or laboratory equipment monitoring).
